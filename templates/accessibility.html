{% trans %}Accessibility guide{% endtrans %}

{% trans %}PyChess can be used with a screen reader and with the keyboard alone. This guide describes what works today. More is on the way, including typing moves.{% endtrans %}

{% trans %}Finding your way around a page{% endtrans %}

  • {% trans %}The first Tab on every page offers two links: "Skip to main content" and this guide.{% endtrans %}
  • {% trans %}Every page has a navigation landmark (the site menu) and a main landmark. The menu sections are buttons: Enter opens one, Escape closes it.{% endtrans %}
  • {% trans %}Game pages have a level 1 heading naming the game, and level 2 headings for the moves, the game actions and the chat.{% endtrans %}

{% trans %}The board{% endtrans %}

{% trans %}The board itself is a picture. Every game, analysis, puzzle and study page also carries a text summary of it, hidden from sight, with these headings:{% endtrans %}

  • {% trans %}Pieces{% endtrans %}: {% trans %}for each side, one line per kind of piece with the squares it stands on, for example "rook: a1, h1". Shogi and janggi use their own square names.{% endtrans %}
  • {% trans %}Pockets{% endtrans %}: {% trans %}in drop variants, how many of each piece are in hand.{% endtrans %}
  • {% trans %}Last move{% endtrans %}: {% trans %}read out whenever it changes: at once in your own games, at the next pause on analysis and puzzle pages.{% endtrans %}
  • {% trans %}Time{% endtrans %}: {% trans %}each clock in words. It is not read out as it ticks; go to it whenever you want to know.{% endtrans %}
  • {% trans %}Status{% endtrans %}: {% trans %}the result of the game, and on puzzle pages whether your move was right. Read out when it changes.{% endtrans %}

{% trans %}On two-board pages such as bughouse, each board has its own summary, headed "Board A: Summary" and "Board B: Summary".{% endtrans %}

{% trans %}Playing on the board with the keyboard{% endtrans %}

{% trans %}Every board can be played from the keyboard. It is one stop in the Tab order, under a level 2 heading "Board", and starts on your king; Tab later returns to the square you left. Playing with the mouse works as before.{% endtrans %}

  • {% trans %}Arrow keys move one square. Up is always away from you, also after the board is flipped. Each square is read out with its piece, for example "e4 White pawn", or just its name when it is empty. A short sound means you reached the edge.{% endtrans %}
  • {% trans %}Enter or Space on one of your pieces picks it up, with a short sound. Enter or Space on another square plays the move, which is then read out as the last move. To pick up a different piece, press Enter on it.{% endtrans %}
  • {% trans %}The number keys jump to a rank in the current file: 1 to 9, and 0 for the tenth. With Shift they jump to a file in the current rank: Shift+1 is the a-file, Shift+3 the c-file. On shogi and janggi boards the numbers count from the lower left corner as the first player sees it, not by the spoken square names.{% endtrans %}
  • {% trans %}A piece letter jumps to the next piece of that kind, of either side: K king, Q queen, R rook, B bishop, N knight, P pawn, and the letters of the variant's other pieces. With Shift it goes back.{% endtrans %}
  • {% trans %}M reads the legal moves of the piece you are on. L reads the last move again, and T both clocks.{% endtrans %}
  • {% trans %}When a move promotes a piece, or gates one in, the choices appear on the board: the arrow keys move between them, Enter picks one, and Escape takes the move back.{% endtrans %}
  • {% trans %}In drop variants, Right arrow at the right edge of the board goes into your pocket (on analysis boards, that of the side to move). Left and Right move through the pieces in hand, and Left from the first one goes back to the board. Pick a piece with Enter, go to a square, and press Enter again to drop it there.{% endtrans %}
  • {% trans %}The page's own keys still work on the board: F flips it, and the question mark lists the shortcuts. When the board does not have focus, the arrow keys step through the moves instead.{% endtrans %}
  • {% trans %}On two-board pages each board has its own keyboard board, headed "Board A" and "Board B".{% endtrans %}
  • {% trans %}If the arrow keys read the page instead of moving on the board, your screen reader is in browse mode. Switch to focus mode: NVDA+Space in NVDA, Insert+Z in JAWS, Orca+A in Orca; in VoiceOver, turn Quick Nav off by pressing Left and Right arrow together.{% endtrans %}

{% trans %}Posting in the forum asks you to find a checkmate in one move. The position is described under the heading that names the side to move, the board works as described above, and the result is read out.{% endtrans %}

{% trans %}Moving through a game{% endtrans %}

  • {% trans %}Left and Right arrow: previous and next move. Up and Down arrow: first and last move. Each step is read out as the last move. These keys work when the board does not have focus.{% endtrans %}
  • {% trans %}Press the question mark key to hear all keyboard shortcuts of the page.{% endtrans %}

{% trans %}Playing and analysing{% endtrans %}

  • {% trans %}Draw, takeback and rematch offers are read out when they arrive, and are answered with Accept and Decline buttons.{% endtrans %}
  • {% trans %}On the analysis board each engine line is a button. Enter plays the line's first move; pressing Enter again follows the line move by move.{% endtrans %}
  • {% trans %}Chat messages are read out as they arrive.{% endtrans %}
